# Multiple Games

A UCP3 module for Stronghold Crusader and Stronghold Crusader Extreme: run as many copies of the
game at the same time as you like. See [module/locale/description-en.md](module/locale/description-en.md).

## Install

Download the zip from the latest release, then in the UCP3 GUI use **Install extension** (or drag
the zip onto the window), press **F5** and enable **Multiple Games**.
